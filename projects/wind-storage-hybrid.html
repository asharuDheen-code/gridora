About this project

Overview

An existing wind farm with a firm connection that was underused for much of the year. Adding storage behind the same connection made better use of an asset that was already paid for.

Challenge

Wind output moves faster and less predictably than solar. Committing to a schedule a day ahead means either under-committing and leaving value on the table, or over-committing and paying for the shortfall. The storage had to absorb forecast error as well as shift energy.

Solution

The two assets present as one plant behind a single controller. Storage takes generation above the committed schedule and covers the gap when the wind drops below it, which narrows the error band enough to commit more confidently. Cycle depth is bounded so the warranty envelope is respected even in a volatile week.

Configuration

  • AC-coupled blocks behind the existing connection
  • Combined plant controller for wind and storage
  • Schedule-following dispatch with forecast error absorption
  • Cycle and depth-of-discharge limits enforced in software
  • Shared substation, protection and auxiliary supply
